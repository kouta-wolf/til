## 概要

Hoisting/TDZ・NaN・thisの理解が不足しているため確認

### Hoisting

hoistingは巻き上げの意味。
```javascript
console.log(name); // undefined
var name = 'マリオ'
```

プログラミングは下に向かって評価するがvarだけは巻き上げが起こりこのようなイメージになる

```javascript
var name;
console.log(name); // undefined
name = 'マリオ'
```

宣言だけHoistingという巻き上げが発生してしまう。
varの有効スコープは関数スコープのため、関数の外までは飛び出さない。
ただしfor文での宣言では飛び出す

```javascript
function test() {
  for (var i = 0; i < 5; i++) {
    // ...
  }
  console.log(i); // => 5 （forブロックの外なのに参照できてしまう）
}

function test2() {
  for (let j = 0; j < 5; j++) {
    // ...
  }
  console.log(j); // => ReferenceError（letはブロックスコープなので外からは見えない）
}
```

という感じで挙動が危なっかしいためES6からは`let`や`const`が推奨されるようになる

### TDZ
Temporal Dead Zone、一時的なデッドゾーンの略で、`let`や`const`は変数にアクセスできない区間を作り出す

```javascript
console.log(hoge); // undefined
console.log(huga); // Cannot access 'huga'...
var hoge = 1;
let huga = 2; // hugaのTDZはここで変数が初期化されたので終了
```

ちなみに`let`や`const`は巻き上げ自体は発生するけれどもTDZによって初期化完了前の変数にアクセスが禁止されているためHoistingが起こってないように感じるとのこと

### this

`this`は誰がこの関数を呼んだかで中身が決まる特殊な変数
呼び出し方次第で形が変わる

呼び出した場所で決まることとアロー関数だけは例外で外側のthisをそのまま使うという2点を覚えておけば大体対応できる。

### NaN

NaNはNot-a-Numberの略でJSにおける非数を表す特別な値
NaNはゼロ同士の除算、NaN値との算術、無効な演算等で出現する
そしてJSではNaN値との比較は全てFalseを返す
