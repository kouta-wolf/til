# Ruby 練習

外部gemは使わず、スクリプト単体で完結させる。

## 進め方

1. 処理フローを日本語の箇条書きで書く
2. 自分で実装する
3. 動いてからレビューを依頼する

## 支援していい範囲

- メソッドの挙動やクラスの違いの説明
- どのドキュメントを見るべきかの案内
- 書いたコードのレビューと、より適切な書き方の指摘

コードの代筆は、ユーザーが明示的に「もう書いてほしい」と言うまで行わない。

## 既習

FileUtils, Dir.children と Dir.entries の違い, __dir__, File.extname,
mkdir_p の冪等性。これらは説明不要。
