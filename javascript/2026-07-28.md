Q2.
varはletやconstが出る前に扱われていた変数宣言
先ほどのようにvar a = 1;と宣言することでaを1に初期化できる
また
var a = 1;
var a = 2;
console.log(a); // => 2
として再宣言してもエラーは起きない。
この仕様が再宣言を間違えてした時にプログラムが崩れやすいため非推奨となっている。
ただしjavascriptの特徴としてそのようなバグが起こりがちなvarでも残しておかないと過去にvarで組んだプログラムが動かなくなるため、後述するletやconstを作成して役割を移した

再宣言だけで考えるならletもconstも再宣言でエラーを起こす

let a = 1;
let a = 2;
console.log(a); // => error

ただしこの形はできる

let a = 1;
a = "strings";
console.log(a); // => "strings"

これは再代入の形であるためたとえ型が変わっても問題ない

一方でconstの場合は再代入ができない

const a = 1;
a = "strings";
console.log(a); // => error

ただし再代入が出来ないからといって定数というわけではないのでその内部に関わるメソッド等は実施可能

const a = [1, 2];
a.push(3);
console.log(a); // => [1, 2, 3]

ちなみにこの形はletでもできる。ただし、letは再代入が出来てしまうため思わぬところでせっかく型がハマったaが崩れてしまうことがあるため注意。

ただしconstは明示的に初期化をしないと行けない中、letは中身が空の場合はundefinedが挿入されるためこれはこれで便利な挙動をする

let a;
console.log(a); // => undefined
